Detailed Workshop Syllabus

Full Stack Development

Learn how modern websites and web applications are designed, coded, and deployed from scratch.

About The Full Stack Workshop

Conducted by senior student developers of Chathurya Student Developers Club, this 5-day hands-on workshop takes you from foundational HTML5 tags to connecting server APIs and database management.

You will write clean, maintainable code, master CSS Grid and Flexbox responsive layouts, build interactive JavaScript UI components, and deploy a capstone project to GitHub Pages.

What You Will Learn

1. Frontend Development

  • HTML5 & Semantic Markup
  • CSS3 Flexbox & CSS Grid
  • Responsive Mobile Interfaces
  • JavaScript DOM Manipulation

2. Backend Development

  • Server-Side Architecture Concepts
  • RESTful APIs & Routing
  • HTTP Requests & JSON Data
  • Authentication & Session Basics

3. Database Concepts

  • Relational Database Basics
  • Tables, Schema & Keys
  • CRUD Operations
  • SQL Query Fundamentals

4. Developer Tools

  • VS Code Setup & Shortcuts
  • Git Version Control
  • GitHub Repository Hosting
  • Browser Developer Console

Detailed Workshop Syllabus

Data Analytics

Master Python data manipulation, cleaning datasets, exploratory analysis, and chart visualizations.

About The Data Analytics Workshop

Learn how to convert raw, unstructured data into valuable insights with Chathurya Student Developers Club. Python is the industry standard tool for data manipulation and visualization.

In this workshop, you will process real-world CSV/Excel datasets, clean missing data, compute summary statistical metrics, and create publication-ready charts using Pandas and Matplotlib.

What You Will Learn

1. Python Fundamentals

  • Python Syntax & Data Types
  • Lists, Tuples & Dictionaries
  • Control Flow & Loops
  • Functions & Reusable Modules

2. Data Handling & Cleaning

  • Loading Datasets (CSV, Excel)
  • Handling Missing Data & Nulls
  • Filtering & Slicing DataFrames
  • Grouping & Aggregating Data

3. Pandas & NumPy

  • Pandas DataFrames & Series
  • NumPy N-Dimensional Arrays
  • Vectorized Array Operations
  • Merging & Joining Data Tables

4. Data Visualization

  • Bar Charts & Column Graphs
  • Line Charts & Trend Curves
  • Pie Charts & Histograms
  • Plotting with Matplotlib
