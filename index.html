About Our Club

Chathurya Student Developers Club

Chathurya Student Developers Club is a premier student-led technical community dedicated to nurturing coding talent, practical software engineering, and data science skills among college students.

Our club actively plans and conducts structured programs focused on student tech growth:

  • Technical Workshops: Intensive hands-on bootcamps in Full Stack & Data Analytics.
  • Technical Events: Hackathons, coding competitions, and guest speaker sessions.
  • Learning Activities: Peer code reviews, open-source sprints, and study circles.
  • Hands-on Development Programs: Real-world capstone projects built from scratch.

CS50P – Introduction to Programming with Python

CS50P, or CS50’s Introduction to Programming with Python, is a free online course by Harvard University taught by David J. Malan. It focuses entirely on learning how to write code, test, and debug using the Python programming language. It is open to complete beginners and requires no prior coding experience.

WebStart 2.0

A Web Start workshop is a beginner-friendly crash course or training program for students. It teaches the core blocks of web development from scratch. Students learn how to build and design their very first interactive websites.
