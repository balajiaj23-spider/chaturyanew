Chathurya Technical Workshop

Data Analytics

Master Excel data cleaning, Power Query, advanced formulas, Power Pivot data modeling, VBA automation, and Tableau analytics dashboards with Chathurya Student Developers Club.

About The Workshop

The Data Analytics Workshop is organized by Chathurya Student Developers Club to empower students to convert raw business data into actionable strategic insights.

In this 5-day hands-on bootcamp, you will clean large real-world datasets, build relational data models, automate repetitive workflows using VBA macros, and build executive Tableau dashboards.

WHAT YOU WILL LEARN

01 – EXCEL DATA CLEANING

  • Import CSV and web data
  • Clean messy values
  • Merge files
  • Power Query

02 – ADVANCED EXCEL

  • XLOOKUP
  • INDEX-MATCH
  • Dynamic ranges
  • Conditional logic
  • Text and date functions

03 – DATA MODELING

  • Power Pivot
  • Relationships
  • Calculated columns
  • Measures
  • Financial modeling basics

04 – AUTOMATION

  • Pivot tables
  • Slicers
  • VBA macros
  • Loops
  • User-defined functions

05 – TABLEAU ANALYTICS

  • Connect Excel/CSV
  • Joins
  • Dimensions and measures
  • Chart types
  • Calculated fields

06 – DASHBOARDS & STORYTELLING

  • Filters
  • Parameters
  • Maps
  • Clustering
  • Dashboard design
  • Publishing and presenting insights

HANDS-ON PROJECTS

  1. Clean a 50,000-row dataset
  2. Build a relational Excel model
  3. Automate repetitive tasks with VBA
  4. Create interactive Tableau charts
  5. Develop a three-page executive dashboard
PRACTICAL CAPSTONE

Sales and Operations Analytics Dashboard

Build and test a complete Sales and Operations Analytics Dashboard from raw data to actionable insights using:

Excel Power Query Power Pivot VBA Tableau
  • Learn by building: Interactive analytics exercises every single session.
  • Practice with real data: Real business dataset transformations.
  • Complete a real analytics project: Showcase a publication-ready Tableau BI dashboard.

Workshop Information
