Chathurya Technical Workshop

Data Analytics

Master Python data handling, clean complex datasets, perform exploratory analytics, and build graphical dashboard visualizations with Chathurya Student Developers Club.

About The Workshop

The Data Analytics Workshop is organized by Chathurya Student Developers Club to empower students to convert raw data into actionable insights using Python—the industry standard tool for data science.

You will work directly with real-world datasets (financial, e-commerce, and academic), learning how to filter noise, handle missing values, calculate statistical metrics, and create presentation-ready charts.

What Students Will Learn

1. Python Basics for Analytics

  • Python Syntax & Data Types
  • Variables, Lists & Dictionaries
  • Control Flow & Conditionals
  • Functions & Reusable Modules

2. Data Handling & Cleaning

  • Loading CSV & Excel Datasets
  • Handling Missing Data & Nulls
  • Filtering & Slicing Datasets
  • Data Transformations & Grouping

3. Pandas and NumPy

  • Pandas DataFrames & Series
  • NumPy N-Dimensional Arrays
  • Vectorized Mathematical Operations
  • Merging & Joining Data Tables

4. Data Visualization

  • Bar Charts & Column Graphs
  • Line Charts & Trend Curves
  • Pie Charts & Distribution Plots
  • Plotting with Matplotlib & Seaborn

5. Basic Analytics & Insights

  • Exploratory Data Analysis (EDA)
  • Identifying Trends & Anomalies
  • Key Performance Indicators (KPIs)
  • Descriptive Statistics Basics

6. Practical Analytics Project

Analyze a real-world multi-table dataset, clean the data, generate key statistical metrics, and present your findings in a final dashboard report.

Workshop Information

Duration 5 Days (Intensive Sessions)
Who Can Attend Students interested in data, analytics, Python, or technology.
Requirements & Prerequisites
  • Basic computer knowledge
  • Laptop recommended
  • No previous programming experience required
