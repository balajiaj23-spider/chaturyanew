Chathurya Technical Workshop

Full Stack Development

Learn how modern websites and web applications are built from scratch. Master frontend UI layout, backend APIs, and database fundamentals with Chathurya Student Developers Club.

About The Workshop

The Full Stack Development Workshop is organized by Chathurya Student Developers Club for students who want to build real-world web applications. In this intensive 5-day hands-on program, you will transition from writing basic HTML elements to assembling complete, interactive, and responsive web platforms.

Under the guidance of senior developer mentors, you will write clean code, understand client-server communication, handle data persistence, and publish your final web project on GitHub.

What Students Will Learn

1. Frontend Development

  • HTML5 Semantic Structure
  • CSS3 Flexbox & CSS Grid
  • Responsive Mobile Layouts
  • Vanilla JavaScript & DOM Manipulation
  • UI/UX Design Fundamentals

2. Backend Development

  • Server-Side Architecture Concepts
  • RESTful API Endpoints & Routing
  • Request/Response Lifecycle
  • HTTP Methods (GET, POST, PUT, DELETE)
  • Authentication & Session Basics

3. Database Concepts

  • Database Storage Fundamentals
  • Tables, Schema & Relationships
  • CRUD Operations (Create, Read, Update, Delete)
  • SQL & Query Essentials

4. Development Tools

  • VS Code Setup & Extensions
  • Git Version Control Workflows
  • GitHub Repository Hosting
  • Browser Developer Tools & Debugging

5. Practical Hands-On Learning

Throughout the workshop, every concept is accompanied by guided coding labs, mini exercises, and a complete capstone web application project.

Workshop Information

Duration 5 Days (Intensive Sessions)
Who Can Attend Students from any stream interested in web development.
Requirements & Prerequisites

  • Enthusiasm to code and build
