Chathurya Technical Workshop

Full Stack Development

Learn how modern websites and web applications are built from scratch. Master frontend UI layout, backend APIs, SQLite database design, and Flask web deployment with Chathurya Student Developers Club.

About The Workshop

The Full Stack Development Workshop is organized by Chathurya Student Developers Club for students who want to build real-world web applications. In this intensive 5-day hands-on program, you will transition from writing basic HTML elements to assembling complete, interactive, and responsive web platforms.

Under the guidance of senior developer mentors, you will write clean code, handle client-server architecture, manage SQLite relational database storage, and deploy a complete capstone project.

WHAT YOU WILL LEARN

01 – HTML

  • Structure real web pages
  • Forms and input elements
  • Tables and data display
  • Semantic tags

02 – CSS

  • Responsive layouts
  • Flexbox for alignment
  • Grid for complex layouts
  • Styling and themes
  • Reusable components

03 – SQL / SQLite

  • Tables and columns
  • Relationships
  • CRUD queries
  • Database design

04 – PYTHON

  • Variables and data types
  • Data structures (list, dict, etc.)
  • Functions and modules
  • Error handling
  • Object-oriented basics

05 – FLASK

  • Routes and URL handling
  • Templates and rendering
  • Forms and validation
  • Sessions and user state
  • CRUD web apps

06 – GIT & VS CODE

  • Version control with Git
  • Branching and merging
  • Commits and history
  • Debugging and workflow
  • Project workflow

HANDS-ON PROJECTS

  1. Build a Responsive Canteen Menu
  2. Design an Order Database
  3. Create a Python Order Calculator
  4. Develop a Flask Pre-Order Web App
  5. Integrate the Complete Full-Stack Project
PRACTICAL CAPSTONE

College Canteen Pre-Order System

Build and test a College Canteen Pre-Order System from start to finish using all the technologies learned during the workshop.

Technology Flow Architecture:

Frontend (HTML & CSS) → Database (SQLite) → Backend Logic (Python) → Web App (Flask) → Test, Run & Deliver
  • Learn by building: Hands-on coding exercises every single session.
  • Practice every day: Step-by-step guidance from senior club mentors.
  • Complete a real project: Add a functional full-stack project to your resume.
